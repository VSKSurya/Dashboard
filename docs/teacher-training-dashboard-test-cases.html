Teacher Training Dashboard Test Cases

Version 1.013 October 2026Manual functional test plan

A practical acceptance suite for the Teacher Training Project Sponsor Dashboard. Run these cases against the connected application when the reporting data and interactive controls are available.

01Test approach

These cases cover the dashboard requirements in the companion PRD. They describe expected product behavior, including behavior that the current visual prototype does not implement yet.

Prototype limitation

The published prototype uses sample figures. Its filters are visual controls and do not filter live data; authentication is a client-side demo. Mark data filtering, permissions, exports, refresh behavior, and security cases as Blocked / Not implemented when testing only that prototype.

Suggested test data: one project with two states, at least two districts and schools, multiple plans and batches, teacher and student participants, records across four dates, one low-attendance batch, one delayed batch, one unassigned trainer, pending certificates, and one location below target.

Execution record: record tester, build/version, browser, date, actual result, status (Pass, Fail, Blocked), and evidence for each case.

Completion criteria

All Must cases pass for the release candidate, failures have owners and resolution plans, and blocked cases are explicitly tied to unavailable features or test data. Confirm the PRD metric definitions and permissions with their owners before sign-off.
