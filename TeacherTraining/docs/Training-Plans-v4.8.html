Reusable Training Plans — v4.8

This revision supersedes the earlier Project → Training Plan relationship. The current model is Training Plan Master → Batch Assignment. Projects own batches; training masters are independent.

Demonstration

  1. Open login.html. Log in with User ID A1 and password Demo@123, or choose Schoolnet Admin in Demo persona mode.
  2. Open Training plans: the fresh/reset sample TP-0001 Digital Teaching – Induction has 4 days and 10 assignments.
  3. Create or modify a master without selecting Project. Enter at least four whole days.
  4. Choose Resource Type, Resource Name and Day, then Add Resource. Rows appear immediately below; preview cards reflect every day.
  5. Duplicate a plan: rename the Copy before saving. Cancel discards staged changes; Save as Draft excludes it from new batch assignment.
  6. Increase duration to six, assign a Day 6 resource, then reduce to four. The conflicting row stays visible; Save is blocked until it is removed or reassigned.
  7. Create a batch in either permitted project. Search active plan codes/names; view selected day-wise resources inline without leaving the batch editor. Start-date/plan changes suggest an end date covering the whole duration.
  8. Modify a used master. Its code stays unchanged; existing batch snapshots retain their original name, duration and links.

History and repository access

Existing browser data migrates without clearing records or replacing legacy codes. Before migration, assigned plans and links are captured for every batch. Historical two-day plans stay two-day snapshots while the reusable master is upgraded to four days. New assignments and Excel batch uploads capture the current master. Referenced masters cannot be deleted; set them Inactive. Project-specific content remains scoped to the batch project, even when the master is reused; common content is reusable. Explicit Include Existing Batches resource propagation remains audited and cannot introduce days outside the assigned snapshot.

Complete package

Existing projects, batch/trainee Excel uploads, simulated OTP and Unique ID lookup, central master uploads, resource bytes, role logins, branded Schoolnet footer, certification samples and attendance/audit workflows remain included.

Technology and validation

Bootstrap 5.3.8, jQuery 4.0.0 and Bootstrap Icons 1.13.1 were verified against official release/download pages on 6 October 2026. JavaScript and CSS are separate. CDN assets are optional for native core interactions; setup-assets.py can vendor all dependencies across all application pages.

51 training-master assertions and the complete regression suite pass. These are non-browser DOM/model fixtures and workbook XML checks. Browser layout, printing, actual IndexedDB and Excel parsing in a real browser were not verified because a browser executable is unavailable. Published credentials, simulated OTP, localStorage and IndexedDB are POC facilities; no backend is included.
