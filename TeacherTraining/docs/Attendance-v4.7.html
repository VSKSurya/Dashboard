Attendance Management · v4.7

Complete POC update · 5 October 2026

Manual attendance process

  1. Select Project from the attendance page.
  2. Select a permitted Batch belonging to that project.
  3. View the trainees and existing marks.
  4. Select the training day or date. Linked controls use batch calendar dates; future days are disabled.
  5. Mark every displayed trainee Present or Absent and select Save attendance.

Confirmed business rules

  1. Attendance may be marked for today.
  2. Attendance may be marked for previous dates.
  3. Attendance cannot be marked for future dates.
  4. Only authorized users may modify attendance. The assigned trainer is the primary recorder; Schoolnet Admin and explicitly granted scoped batch managers can also correct marks.
  5. Attendance changes are audited with actor, timestamp, before/after status and project linkage.
  6. Every mark is linked to a trainee, batch and training date. Corrections update that tuple rather than adding duplicate marks.

Excel bulk upload

Use Download attendance template or templates/attendance-template.xlsx. The generated batch template includes its Project Code, Batch Code, current Trainee IDs and a training date, with blank Attendance cells for explicit Present/Absent entry.

ColumnValidation
Project CodeMust match the selected batch project.
Batch CodeMust be the selected permitted batch.
Trainee IDMust belong to that batch.
Training DateYYYY-MM-DD or Excel serial; today/previous valid training dates only.
AttendancePresent or Absent; blank/other values are rejected.

Select Bulk upload attendance, choose the XLSX workbook and Validate attendance upload. Review each row, current → uploaded status and errors. Save validated attendance rechecks permissions, current batch/trainee membership and dates. One invalid row prevents the whole upload from being saved. Duplicate trainee/batch/date rows in the workbook are rejected. Uploads may cover multiple previous dates within the selected batch.

Corrections and history

Valid existing marks are updated with before/after audit entries; new marks are added. Unchanged values do not add a change audit event. Missing workbook rows leave existing data unchanged; absence is never assumed from a missing row. Storage failure restores metadata and audit. Attendance corrections feed existing completion, certification and MIS calculations.

Review contracts and boundaries

Manual save requires an explicit mark for each current trainee. Bulk save accepts the rows supplied for the selected batch. Batch-period date limits and blocking corrections after final batch closure are POC policies pending business sign-off; no prior-date cutoff or extra approval is invented. National/state/project holidays remain schedule validation rules rather than automatic attendance values. Binary XLS is not supported; imports use the first XLSX worksheet.

Audit and permissions are local browser demonstrations. Secure server authorization, shared attendance, transactional concurrency and immutable audit require a backend. Tests exercise real action functions with non-browser DOM/Excel-input fixtures, generated XLSX structure and rollback/revalidation. Actual browser workbook parsing/layout and server behavior remain unverified.
