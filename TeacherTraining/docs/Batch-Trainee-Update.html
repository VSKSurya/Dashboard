Batch screens and workflow

Batch management → Upload batches from Excel → download template → populate rows → upload → inspect validation and actual UDISE location → Save validated import. No records save at selection/preview; every row and current scope are checked again before committing. Invalid rows block the entire import. Edit uses the same date, plan/project, capacity, trainer and holiday rules. School choice derives the read-only actual location. Reference text is separate and never overrides the directory location. Authorized deletion prompts confirmation; linked/closed histories remain protected.

Schoolnet Admin → Batch permissions → select ERNET/State/School Admin → explicit scoped grant → save. Granted Admin can create/import/edit/delete within assigned project/state/school scope and manage trainees there; assigned trainer can bulk upload/close registration/approve trainees but has no automatic batch edit/delete grant. Exact roles are provisional pending business confirmation.

Trainee Registration reaffirmed

  1. Open registration enabled/disabled per batch; registration link available when enabled.
  2. Link resolves the exact batch; no fallback for an invalid link.
  3. Self and bulk registrations count toward maximum capacity, including pending approvals.
  4. Day 1 only is provisional; within-batch alternative available in review settings.
  5. Trainer/authorized Admin can close registration.
  6. Bulk trainee XLSX upload remains available when open registration is enabled or disabled, before final closure.
  7. Assigned trainer must approve the entire list before final batch closure. Completion criteria remain separate gates.
  8. Duplicate identity is normalized mobile OR email within the batch, checked against existing and staged rows.

Self-registration: exact batch link → synthetic name + mobile/email → Request demo OTP → enter displayed 123456 → Verify and register → generated Unique ID shown. Unique ID lookup uses a separate contact/OTP form and remains available when registration is closed/full/outside its window. No SMS/email is delivered. Mobile versus email mandatory/applicability, OTP expiry/retries and lookup disclosure remain Business clarification required.

Review states

Loading: Parsing and validating workbook. Valid preview: explicit Save validated import enabled. Invalid preview: row errors, save disabled, nothing saved. Changed data at commit: revalidation error and no save. Save success: count of stored rows and local audit entries. Empty list: scoped empty message. Unauthorized action: explicit denial. Closed/linked record deletion: explain pending policy. Invalid edit/self-registration: inline errors preserve form input.

Business clarification required

Confirm permission matrix; unique ID format/scope; mandatory fields/limits; binary XLS support, exact workbook contract, size limits and partial-save policy; trainer availability/holiday overrides; live UDISE integration/location history; edit/delete/reopen and linked-record retention; final registration window, OTP/contact identity/duplicate scope and final closure rules.

Prototype assumptions and suggested UX

Schoolnet Admin controls explicit scoped Admin batch grants; global unique batch code; positive integer size; end ≥ start; one availability interval covers whole batch; holidays block without override; first-sheet XLSX named headers and atomic save; location fetched from synthetic directory; closed/linked histories protected. Registration remains fixed demo OTP and Day 1 window with review alternative. Suggested UX: visible code/name plan choice, actual-versus-reference location, per-row preview, prominent Excel primary action and Manage trainees shortcut.
